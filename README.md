# tonytony0730 的個人網站

用繁體中文製作的單頁個人網站，包含自我介紹、精選作品和 GitHub 聯絡連結。

- 在瀏覽器開啟 `index.html` 即可預覽。不用安裝套件或執行建置。
- 編輯 `index.html` 更換顯示名稱、自介與作品；編輯 `style.css` 調整版面與配色。
- 網站使用相對路徑，因此也能部署到 GitHub Pages 專案子目錄。

## 發佈到 GitHub Pages

1. 在 GitHub 建立 `tonytony0730/tonytony0730.github.io` 儲存庫；如果已有該儲存庫，先檢查現有網站檔案。
2. 把這個資料夾內的檔案放到儲存庫 `main` 分支根目錄（包含空白的 `.nojekyll`，讓 GitHub 直接提供靜態檔案）。
3. 在儲存庫的 **Settings → Pages** 選 **Deploy from a branch**，選擇 **main** 與 **/(root)** 後儲存。
4. 等待部署完成，再到 **Settings → Pages → Visit site** 驗證。預期網址為 `https://tonytony0730.github.io/`。

[GitHub Pages 官方快速入門](https://docs.github.com/en/pages/quickstart)
